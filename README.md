# Shrinkium player guide

DocMD documentation for the Hytale support branches. Read the source guide in versions/hytale0.7/index.md.

Install Node22 and Python3, then run npm ci --ignore-scripts, npm run build and npm run check. Output is site/. This source branch does not itself establish a hosted website or publish mod files.

The runtime source lives on hytale0.7. Guides follow Hytale families independently of mod releases; update matching player-facing behavior and preserve the root version chooser. Promotional art and native screenshots are labelled separately.
