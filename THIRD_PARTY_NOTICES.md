# Asset and dependency notices

Shrinkium is an independent Hytale mod and is not an official Hypixel Studios product.
Hytale names and game visuals belong to their respective owners. Game/server binaries,
stock asset archives and toolchains are not distributed with this repository.

The mod references native Hytale assets by ID. Gameplay screenshots and the rendered
ore icon show the game's native stone and world art. Shrinkium's ray, crystals,
mineral outcrops, painted textures and interface artwork are original mod assets.
Promotional banner and logo artwork was made with OpenAI image generation. It is
illustrative artwork, separate from the native gameplay captures.

The fire, restoration, selection and handling cues were generated through ElevenLabs
using its Sound Effects model. Sanitized export/model/settings provenance is in
provenance/audio.json. No provider credentials or temporary download links are included.

Optional asset authoring uses Pillow (HPND) and NumPy (BSD-3-Clause). Building the mod
requires a separately obtained Hytale SDK and JDK 25. This repository currently grants
no open-source license to Shrinkium's own code or art; no redistribution license has
been selected.

The player guide uses DocMD (@docmd/core0.9.8), licensed under MIT. Its complete
license notice is retained in assets/publication.css and the compiled guide.
